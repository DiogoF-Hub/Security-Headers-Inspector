Security Headers Inspector

Privacy

Browsers don't keep the Strict-Transport-Security and Set-Cookie headers in their cache, so a page loaded from cache looks like it's missing them. When on, the extension requests such a page once more from the site (without cookies) to get the full set, unless it already saw the same page load from the network in this session. It also scans the tabs that are open when you install the extension. When off, the toolbar grade can be wrong for cached pages, but the popup still re-checks when you open it. Never used for Incognito tabs.

Cookie values often contain session tokens. When on, they are blurred until you click them. Copied headers always hide cookie values.

Display

Displays the letter grade of the current page as a badge on the extension icon.
